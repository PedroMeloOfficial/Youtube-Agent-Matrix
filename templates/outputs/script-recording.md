## Formatting rules for this file — they are the point

The technical script is dense on purpose, and this file exists because that density is unreadable
while a camera is running. So:

- **No markup characters in the body.** No asterisks, no backticks, no square-bracket markers, no
  bold, no italics, no emoji. If a line needs weight, say so in the direction line above it in
  plain words.
- **No tables** anywhere except the closing shot list.
- **No timestamps down to the second.** A rough minute marker per block is enough to know where
  you are. Precise timing lives in the technical script.
- **No production jargon.** "Punch in", "interrupt", "B-roll", "pattern break", "cold open" are
  agent vocabulary. Write what the creator actually does: "cut in closer", "cut away to the
  screen recording here", "this is the opening line".
- **Two elements per block, always in this order:** what is happening in the scene, then the
  words. The single permitted exception is a one-line emphasis cue between spoken paragraphs
  ("slow down here", "this is the line to land"), and only where the technical script marked
  that line `[EMPHASIS]`. Nothing else goes between the words.
- Spoken text is written as its own paragraphs, exactly as it will be said, with nothing wrapped
  around it.
